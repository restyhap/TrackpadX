## 3. 核心数据流

```
[手指动作]
  ├─ HID 层: cghidEventTap(defaultTap) ──拦截型──> TouchpadBlockerService（返回 nil 丢弃误触）
  └─ Session 层: cgSessionEventTap(listenOnly, gesture mask)
        └─ 回调: 仅转发 cgEvent 转主线程 → NSEvent(cgEvent:) → allTouches()
              └─ ThreeFingerDownRecognizer 状态机（接触数==3、质心位移>阈值、ended、冷却）
                    └─ 触发 → MinimizeWindowService
                          └─ NSWorkspace.frontmostApplication → AXUIElementCreateApplication
                               → kAXFocusedWindowAttribute → AXUIElementPerformAction(AXMinimize)
                               失败 → （待实测）hide() 或静默
```

关键约束（沿 02 文档）：
- tap 回调不做重活，只投递主线程队列（AltTab 教训）；
- `NSEvent(cgEvent:)` 必须主线程；
- `guard touch.isDirect` 后再取 `normalizedPosition`；
- tap 被 `tapDisabledByTimeout` 禁用时重新启用（TouchpadBlocker 已有实现可迁移）。
